Anime Studio AI

Generate anime & cartoon videos from text prompts, links, or sketches with voice sync, custom characters, dynamic BGM, and multilingual dubbing.

📱 About This Project & GitHub Pages

यह रिपोजिटरी एक Native Android App (Kotlin & Jetpack Compose) है, सामान्य HTML/JS वेबसाइट नहीं। GitHub Pages केवल स्टेटिक वेब पेजों को होस्ट करता है। एंड्रॉइड ऐप का उपयोग करने के लिए नीचे दिए गए निर्देश देखें।

🚀 How to Run & Install the App

  1. In Google AI Studio Build: View and test the live app directly in your browser using the built-in Streaming Android Emulator.
  2. On Your Android Device: In AI Studio, open the project menu → select Export → click Generate APK. Download the .apk file to your Android phone and tap to install.
  3. In Android Studio (Local PC): Clone this GitHub repository to your computer, open it in Android Studio, and click Run (Shift + F10) on an emulator or physical device.

✨ Features in Anime Studio AI

🎬

Anime Video Studio

Multi-scene anime screenplay generation from prompts, web articles, or scanned manga sketches.

🎙️

Voice Sync Engine

Lip-sync visual animations with character-customized pitch, speed, accent, and mood.

👤

Character Builder

Design avatars, hair styles, eye colors, outfits, and assign custom voice personas.

🎵

Dynamic Music Synth

Real-time background music generation (Action, Battle, Emotional, Shonen, Cyberpunk).

🌐

Multilingual Dubbing

Instant audio & subtitle dubbing across Japanese (日本語), Hindi (हिंदी), English, and Spanish.

📦

Download & Storage

Room SQLite database vault, photo upload picker, JSON project backups, TXT scripts, and SRT subtitles.

Built with Kotlin, Jetpack Compose, and Room Database.
